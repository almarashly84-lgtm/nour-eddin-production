# موقع نور الدين للإنتاج + لوحة التحكم

موقع استوديو ومكتب إعلامي في فيينا بثلاث لغات (العربية، الألمانية، الإنجليزية)، مع لوحة تحكم كاملة.
يعمل على **Cloudflare Workers** مع قاعدة بيانات **D1** وتخزين ملفات **R2** (صور، فيديو، موسيقى).

## لوحة التحكم `/admin`

الإحصائيات · الموسيقى (رفع MP3، اختيار المقطع، مستوى الصوت، تشغيل/إيقاف، شاشة الترحيب) · الخدمات · الأعمال (صورة حتى 6 MB، فيديو حتى 95 MB) · السيرة الذاتية · التواصل والمنصات · النصوص وSEO · Impressum · الأمان.

لا يوجد رابط للوحة داخل الموقع. تُفتح بكتابة `/admin` بعد اسم الموقع.

**الأمان:** كلمة السر مشفّرة (PBKDF2) · جلسة بـ Cookie محمي تنتهي بعد 7 أيام · قفل 15 دقيقة بعد 5 محاولات خاطئة · حماية من الطلبات القادمة من مواقع أخرى · كل البيانات تُفحص على السيرفر · نوع كل ملف مرفوع يُفحص من محتواه وليس من اسمه · روابط المنصات تُقبل فقط إن بدأت بـ https · النصوص تُعرض كنص فقط (لا XSS) · سياسة أمان (CSP) تمنع أي سكربت خارجي · لا تُحفظ أسماء أو أرقام الزوار في الإحصائيات.

**الحماية من الإغراق والتوقف (23.10.2026):** تحويل http إلى https · حدّ لكل زائر على الإحصائيات (40/دقيقة) وعلى تسجيل الدخول (8/دقيقة) عبر Workers Rate Limiting · سقف يومي 5,000 حدث إحصائي حتى لا تُستهلك حصة D1 المجانية المشتركة بين كل مواقع الحساب · الإحصائيات تُجمع عدّادات يومية (لا صف لكل نقرة) ولا تُقبل إلا عناصر موجودة فعلاً في الموقع · إن تعطلت قاعدة البيانات يفتح الموقع من آخر نسخة سليمة (ذاكرة ← Cache ← النسخة المدمجة) · نسخة workers.dev لا تُفهرس في Google · لوحة التحكم: حفظ التعديلات غير المحفوظة عند انتهاء الجلسة، تنبيه عند الحفظ من جهازين، نسخة احتياطية تنزيلاً واستعادة.

## الرفع على Cloudflare لأول مرة

1. ارفع هذا المجلد إلى مستودع GitHub جديد باسم `nour-eddin-production`.
2. أنشئ في Cloudflare قاعدة بيانات D1 باسم `nour-db` وتخزين R2 باسم `nour-media`، وضع `database_id` في `wrangler.jsonc` (تم: `nour-db` و `nour-media` مُنشآن في حساب علاء).
3. في Cloudflare: **Workers & Pages ← Create ← Import a repository** واختر المستودع.
   - اسم المشروع يجب أن يكون `nour-eddin-production` بالضبط (مثل `name` في `wrangler.jsonc`).
   - اترك Build command فارغًا.
4. في **Settings ← Variables and Secrets** أضف سرّين من نوع **Secret**:
   - `ADMIN_INITIAL_PASSWORD` كلمة سر مؤقتة لأول دخول (تُغيَّر إجباريًا بعد الدخول).
   - `IP_SALT` نص عشوائي طويل.
5. **Settings ← Domains & Routes ← Add ← Custom domain** واكتب الدومين.
6. افتح `/admin`، ادخل، غيّر كلمة السر، ثم املأ البيانات الحقيقية.

> تنبيه: الدومين `nour-eddin.com` موجود مسبقًا وعليه إيميل `studio@nour-eddin.com`. عند ربطه، انسخ سجلات الإيميل (MX و SPF و DKIM) كما هي، واتركها رمادية (DNS only)، حتى لا يتوقف الإيميل.

## للمطوّر

```bash
npm install
npx wrangler dev        # تشغيل محلي على http://localhost:8787 (أسرار التجربة في .dev.vars)
npm run check           # فحص HTML
python3 tools/icons.py  # إعادة بناء الأيقونات وأغلفة الأعمال التجريبية
```

ملفات `/assets/` و `/fonts/` تُحفظ في المتصفح سنة كاملة. عند تعديلها غيّر `?v=` في روابطها داخل ملفات HTML.
